
##  Hướng dẫn sử dụng

1. Tải file HTML về máy.
2. Mở file bằng trình soạn thảo code như VS Code hoặc Notepad.
3. Tìm dòng sau:

```javascript
const TEN='';
```

4. Điền tên người muốn gửi lời chúc vào giữa hai dấu nháy đơn. Ví dụ:

```javascript
const TEN='Ngọc Anh';
```

5. Lưu file và mở bằng trình duyệt để xem kết quả.

 **Chúc bạn có một ngày 20/10 thật vui vẻ và ý nghĩa!**
